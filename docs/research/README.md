# Research and spikes

Primary sources behind the decisions recorded on the [build-spec map](https://github.com/rtmkvtn/lendloop-test/issues/1) and in `docs/adr/`. They describe the state of the libraries when they were written (November 2026) and are not kept up to date.

- [convex-clerk-compose.md](convex-clerk-compose.md): self-hosted Convex in docker-compose, and how Clerk authenticates against it.
- [n8n-capabilities.md](n8n-capabilities.md): n8n 2.47.3 HMAC verification, retries, the Error Workflow, credential-free exports and CLI import.
- [spike-convex-compose.md](spike-convex-compose.md): runtime checks of service-name networking, admin-key stability, codegen output and crons, with the [compose file](spike-convex-compose.docker-compose.yml) used.
- [../prototypes/ui-screens.prototype.html](../prototypes/ui-screens.prototype.html): the three throwaway UI layouts compared before the build. Open it in a browser; `?variant=A|B|C` switches layout.
